# WrongCalc 3000 🧮💥
> The Confidently Incorrect & Utterly Useless Calculator.

A modern web application built for maximum comedic effect, featuring intentionally faulty arithmetic, quantum overthinking, gaslighting mode, and tactile Web Audio sound synthesis.

---

## ✨ Features

- 💥 **Chaotic Evil**: Classic Orwellian math (`2 + 2 = 5`), swapped arithmetic operators, and black hole division-by-zero crashes.
- 🤷 **Gaslight Mode**: Computes a real answer, but rewrites your input history so you doubt your own senses.
- 🔤 **String Math**: JavaScript type coercion absurdity (`"8" + "9" = "89"`, `5 - 2 = "[object Object]"`).
- 🌌 **Overthinker (`🤔`)**: Runs multi-step simulated quantum physics computations only to output `42`.
- 🤏 **Off-By-One**: Subtly infuriating deviations (`10 - 3 = 6.99999998`).
- 🎲 **Shuffle Keypad**: Reorganizes all buttons dynamically for maximum cognitive dissonance.
- 🔊 **Web Audio Synthesizer**: Procedural tactile clicks, error buzzers, and panic sirens with zero external assets.
- 🎨 **Obsidian Glassmorphic UI**: OLED digital readout with CRT scanlines and Google Fonts typography.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve
```
